\# My Setup Notes (Windows)



\## What I installed

\- Node.js (LTS) from nodejs.org

\- Git from git-scm.com



\## How I uploaded this project to GitHub

1\. git init -b main

2\. git add .

3\. git commit -m "message"

4\. git remote add origin https://github.com/k-sahi/n8n-mcp.git

5\. git push -u origin main



\## Things I learned

\- GitHub doesn't accept normal passwords for git; use browser sign-in or a token

\- `git add` picks files, `git commit` saves a snapshot, `git push` uploads it

\- The contributors list comes from commit history
